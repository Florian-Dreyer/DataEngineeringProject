Key behaviours

  • Search filters on recipe name + ingredients (case-insensitive, reads from PostgreSQL dim_recipe or parquet fallback)
  • Filters: cook time slider, min Bayesian rating, cuisine tag (parsed from tags column)
  • Radar chart: Plotly polar chart with 5 axes — Protein, Fat, Carbs, Sugar, Sodium — values normalised to % of typical daily intake for visual comparison
  • Nutrition bars: colour-coded (green = good, amber = moderate sugar, red = high sodium)
  • Trend badge: shows "🔥 High / Medium / Low demand" if trend_index available, else hidden
  • Shop on Amazon Fresh: builds amazon.com/s?k=ingredient1+ingredient2... from top_ingredients
  • Instacart: builds instacart.com/store/s?k=recipe+name+ingredients
  • Pagination: 10 results per page, Streamlit session state
